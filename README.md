## 🚀 Featured Projects

### [OpenFriends](https://github.com/zxrafa/OpenFriends)
> **Minecraft Java Fabric Mod with P2P LAN Tunneling and Cloud Backend**
- **Technologies:** Java (Fabric Loader, Sponge Mixins), Python (FastAPI, SQLite, Uvicorn), e4mc Tunnel Protocol
- **Overview:** Engineered an offline-friendly social network and 1-click multiplayer connection system for Minecraft. Uses runtime bytecode injection (Mixins) to capture e4mc secure tunnel domains, syncs player presence with a lightweight FastAPI backend, and renders a native in-game interface.
- **Key Features:** Zero-port-forwarding multiplayer, real-time presence heartbeats, integrated friend management GUI, and binary releases.

### [ProMap Analytics (Sofascore Heatmap Generator)](https://github.com/zxrafa/sofascore-heatmap)
> **Interactive Sports Analytics & Tactical Heatmap Engine**
- **Technologies:** React 19, TypeScript, Vite, HTML5 Canvas 2D API, Tailwind CSS
- **Overview:** A client-side data visualization tool inspired by broadcast analytics platforms (Sofascore, Opta). Dynamically renders pitch geometry and calculates multi-point Gaussian-like radial density matrices in real time.
- **Key Features:** Dual brush modes (Draw/Erase), customizable intensity/radius, tactical role presets (Box-to-box, Winger, Striker), orientation toggle, and high-resolution PNG export.

### [YT Downloader](https://github.com/zxrafa/ytdown)
> **Desktop Media Processing Application with Automated Packaging**
- **Technologies:** Python 3, Flask, `yt-dlp`, FFmpeg, PyInstaller, Inno Setup
- **Overview:** A local desktop utility for media extraction and audio processing. Combines a modern dark-mode web interface with a local Flask service running background download workers and progress polling.
- **Key Features:** Asynchronous background job threads, format and quality selection, automated Windows installer (`.exe`) generation with bundled FFmpeg binaries.

### [AR Browser Experiment](https://github.com/zxrafa/ar-browser)
> **Web-based Augmented Reality & MediaStream Exploration**
- **Technologies:** JavaScript, HTML5 Canvas, WebRTC (`navigator.mediaDevices.getUserMedia`)
- **Overview:** Prototype exploring browser camera integration and real-time interactive graphic overlays, demonstrating practical curiosity with standard web hardware APIs.
